## Game Development & XR Projects

### 1. Chrono Rebellion (Unity | C# | HDRP)
Chrono Rebellion is a third-person and first-person sci-fi shooter developed in Unity using C# and the High Definition Render Pipeline (HDRP). It features time-manipulation combat mechanics, weapon switching, enemy combat systems, a custom sci-fi HUD, responsive player controls, and interactive level mechanics.

### 2. Behind the Smile (Unity | C# | Global Game Jam 2026)
Behind the Smile is a narrative-driven 3D game created in 48 hours during Global Game Jam 2026 around the official theme "Masks". Syed Muhammad Ahmad collaborated in a jam team and implemented core gameplay mechanics, player interactions, user interface (UI), and game state systems in Unity and C#.

### 3. Paper Plane Dash (Unreal Engine 5 | Blueprints)
Paper Plane Dash is a third-person endless runner built in Unreal Engine 5 using Blueprints visual scripting. It features procedural level generation, smooth lane switching, obstacle avoidance, a dynamic HUD, and a live scoring system.

### 4. Solar System Exploration (VR) (Unity | OpenXR | XR Interaction Toolkit)
Solar System Exploration is an immersive Virtual Reality (VR) educational application built with Unity, OpenXR, and the XR Interaction Toolkit. Players use VR teleportation locomotion and controller interactions to explore planets and read world-space educational UI panels.

### 5. Voxelcraft 3D
Voxelcraft 3D is a voxel-based 3D sandbox game inspired by block-building worlds, featuring procedural terrain blocks, first-person exploration, and block placement/destruction mechanics.

### 6. Pac-Man (C++ | SFML)
A classic 2D Pac-Man arcade recreation programmed in C++ using the Simple and Fast Multimedia Library (SFML). It implements enemy ghost AI, collision detection, and scoring mechanics, and applies Graphs, QuadTrees, and other data structures to optimize gameplay performance.

### 7. AR Memory Card Game (Unity | Vuforia | C#)
A marker-based Augmented Reality (AR) memory card matching game built in Unity with the Vuforia Engine and C#. It uses camera image-target recognition to spawn 3D cards on physical markers, complete with flip animations, pair-matching logic, and a scoring system.

### 8. AR Face Filter App (OpenCV | Python | MediaPipe)
A real-time Augmented Reality face filter desktop application written in Python using OpenCV and Google MediaPipe. It tracks 468 facial landmarks from a live webcam feed and composites interactive overlays such as neon glasses, face frames, and eye-glow effects in real time.

### 9. Interactive 3D WebGPU Portfolio (Three.js | TSL | Blender | After Effects | RAG)
This portfolio website itself: a rainy cyberpunk alley powered by Three.js WebGPU and Three Shading Language (TSL) with GPU height-map rain collision, wet-ground planar reflections, a custom rigged 3D avatar created in Blender 5.1, a 46-second promotional video with FilmBro VFX overlays and an original synthesized CC0 synthwave soundtrack, a Gemini RAG AI chatbot with clickable citations, and a Resend-powered email contact system.
